# 🚀 My Python Projects Collection

Welcome to my portfolio! This repository contains various Python applications, ranging from academic tools to automation systems.

## 🍱 1. Student Meal Control System
An automated system designed to manage student cafeteria access.
- **File:** `meal_card_control_system.py`
- **Key Features:**
    - Prevents double-eating using date-time logic.
    - Saves data locally in a JSON file (Data Persistence).
    - Validates authorized Student IDs.

## 📊 2. GPA Calculator
A practical tool for university students to track their academic performance.
- **File:** `GPA_calculator.py`
- **Key Features:**
    - Calculates Semester GPA based on credit hours and grades.
    - User-friendly terminal interface.

## 🔗 3. QR Code Generator
A utility to convert text or URLs into scannable QR codes.
- **File:** `QR_CODE_GENERATOR.py`
- **Key Features:**
    - Uses the `qrcode` library to generate high-quality images.
    - Useful for sharing links or contact information.
