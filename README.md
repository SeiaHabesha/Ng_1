# Restaurant Menu QR Code Generator
This Python script generates a custom QR code for restaurants and hotels to display their daily menus.

## How to use
1. Install requirements: `pip install qrcode[pil]`
2. Run the script: `python main.py`
3. Scan the generated `Restaurant_Menu.png` with your phone!

## Technologies Used
* Python
* qrcode library
* Google Colab (for testing)
