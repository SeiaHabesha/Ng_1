# ⌨️ Professional Python Virtual Keyboard

A modern, functional, and fully-featured Graphical User Interface (GUI) virtual keyboard built using **Python** and the **Tkinter** library.

## 🚀 Why this Virtual Keyboard?

Unlike many other virtual keyboards that rely on external libraries like `pyautogui`, this project is designed to be **standalone**. It has a built-in text display area, which means:
* **No Admin Privileges Required:** It works perfectly on restricted environments (like university computers).
* **No External Dependencies:** You don't need to run `pip install` for extra libraries.
* **Portable:** Just run the script and start typing.

## ✨ Key Features

* **Internal Display Area:** Type directly into the integrated text box within the application.
* **Full QWERTY Layout:** A complete set of keys including letters, numbers, and symbols.
* **Intelligent Shift & CapsLock:** Working logic for upper/lower case and special symbols (e.g., `!`, `@`, `#`).
* **Special Keys Support:** Included functional keys like `Tab`, `Enter`, `Space`, and `Backspace`.
* **Interactive UI:** Visual feedback when Shift or CapsLock is active (the display background changes color).
* **Topmost Window:** The keyboard stays on top of other windows for easy access.

## 🛠️ Technology Stack

* **Language:** Python 3.12
* **GUI Framework:** Tkinter (Standard Library)

## 📦 Installation & Usage

1.  Ensure you have **Python** installed on your system.
2.  Download the `keyboard_final.py` file.
3.  Run the script:
    ```bash
    python vertualkeyboardl.py
    ```
4.  Start typing using your mouse!
